# Локальний калькулятор затирки

Запуск: `npm run dev -- --hostname 127.0.0.1 --port 3000`.
Сторінка: http://127.0.0.1:3000/grout-calculator.
Вкладка та нові API доступні тільки в режимі розробки. У production API повертають 404.

## Дані

Сервер читає всі сторінки пошуку «заповнювач» з наявного API АГРОМАТ,
залишає категорію «Заповнювачі швів» і виключає видалені товари.
Використовуються наявні серверні `AGROMAT_API_BASE_URL` і `AGROMAT_API_KEY`.
Результат кешується на п'ять хвилин, а копія — у `data/grout-catalog.json`.
Кнопка «Оновити базу» запускає повторне завантаження. При недоступному API
показуються збережені дані з датою та попередженням. Останній резерв —
існуючий історичний `data/products-lite.json.gz`, у якому немає повних характеристик.
Записи й налаштування основної бази не змінюються.

Фасування береться з атрибута пакування, інакше з явної маси в назві.
Вартість розраховується як кількість цілих упаковок × ціна упаковки.
Щільність 1,8 — ручне початкове припущення з наданого Excel, а не
перевірена характеристика обраного продукту. Формула використовує глибину шва.

## ШІ

Без ключа працює текстовий пошук та показ фактів із каталогу. Це не ШІ-консультація.
Для Gemini введіть ключ у розділі «Підключення ШІ» на сторінці.
Він зберігається тільки в стані React до закриття/оновлення сторінки,
не записується на диск або в localStorage.
Альтернатива: `GEMINI_API_KEY` у `.env.local` і перезапуск dev-сервера.
Модель задається серверною `GEMINI_MODEL`, початково `gemini-3.8-flash`.
Реальна генерація потребує чинного ключа, доступу до моделі та квоти.

Google отримує питання, до шести останніх повідомлень, обраний товар,
до шести релевантних записів каталогу та готовий розрахунок.
Числа розраховує код, не мовна модель. Відповідь моделі відображається
звичайним текстом; посилання на джерела формує інтерфейс з даних каталогу.
Техкарти виробників та вміст приватного NotebookLM не імпортовані.
При недостатніх даних помічник має вказувати, що потрібна техкарта.

## Перевірки

`node --test tests/grout-calculator.test.mjs`

`npm run typecheck`

Перевірено розрахунок за прикладом Excel, використання глибини, запас,
округлення упаковок, перевірку введених значень, пошук, фасування та URL джерел.
